# Como limpar o cache do navegador e garantir que está usando o código atualizado

## Método 1: Limpeza rápida (recomendado)
1. Abra as DevTools (F12 ou Cmd+Option+I no Mac)
2. Clique com o botão direito no ícone de recarregar
3. Selecione "Esvaziar cache e recarregar" ou "Hard Reload"

## Método 2: Atalhos de teclado
- **Windows/Linux:** Ctrl + Shift + R
- **Mac:** Cmd + Shift + R

## Método 3: Limpeza completa do cache
1. Abra as DevTools (F12)
2. Vá para a aba Application/Storage
3. No menu lateral, clique em "Clear Storage"
4. Marque todas as opções
5. Clique em "Clear site data"

## Método 4: Modo incógnito
Abra uma nova janela incógnita/privada e acesse o site novamente

## Para verificar se está usando a versão correta:
1. Abra o DevTools
2. Vá para a aba Sources
3. Procure por AppointmentFormSimple
4. Verifique se NÃO há "require" no código
